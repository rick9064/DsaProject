# DSA Algorithm Manager

The **DSA Algorithm Manager** is a web application designed to help users explore and test various Data Structures and Algorithms (DSA). It provides an interactive platform to run algorithms like **Linear Search**, **Sorting**, **Queue Operations**, and **Binary Tree Traversals** while learning about their functionality.

## Features

- **Interactive Testing**: Input arrays or values to test different algorithms.
- **Algorithm Explanations**: Each algorithm includes a brief description and a button to view the Python code.
- **Real-Time Results**: Instant feedback for operations like search or sort.
- **Backend Integration**: The app connects to a Python backend to process algorithm logic.
- **Responsive Design**: Works seamlessly on both desktop and mobile devices.

## Technologies Used

- **Frontend**: Built with **React** for dynamic user interfaces and **CSS** for styling.
- **Backend**: **Python** is used to implement algorithm logic.
- **API**: The frontend communicates with the backend to perform algorithm operations.

## Supported Algorithms

1. **Linear Search**: Find an element in an array.
2. **Sorting Algorithms**: Sort an array using **Bubble Sort**.
3. **Queue Operations**: Perform **enqueue** and **dequeue** operations.
4. **Binary Tree Traversals**: Visualize **Inorder**, **Preorder**, and **Postorder** traversals.





## How to Run

1. Clone the repository.
2. Run the frontend with `npm start`.
3. Set up the backend (Python server) and make sure it's running.
